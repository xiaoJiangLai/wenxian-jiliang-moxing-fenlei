# 文献计量模型分类索引

一个用于学习计量经济学模型的文献索引工具。收录 64 篇经济学学术文献，按核心计量模型分为 9 个大类，支持按文章标题/作者检索，并查看每篇文献使用的计量模型。

## 功能

- **模型大类归类**：断点回归（RDD）、双重差分（DID）、工具变量法（IV/2SLS）、固定效应面板、空间计量、全要素生产率测度（TFP/DEA）、一般均衡/理论模型、综合指数测度、质性/纯理论/案例研究。
- **按标题/作者检索**：输入文章标题关键词或作者名，实时检索对应文献，并显示其所用计量模型。
- **按大类快速筛选**：点击大类标签即可只看该类的文献。

## 使用

直接用浏览器打开 `文献计量模型分类索引.html` 即可，无需任何依赖。

## 文件说明

- `文献计量模型分类索引.html` —— 可交互的网页版索引（推荐）
- `文献计量模型分类清单.md` —— Markdown 表格版分类清单
